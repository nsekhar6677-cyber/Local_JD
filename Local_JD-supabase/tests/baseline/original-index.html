About this app & data

All flat, owner, PIN and payment data is stored for this society and shared with anyone who signs in here — owners only see their own flat's ledger, admins see everything. This runs as a web app (works on iPhone, Android and desktop browsers); for an app-like icon, open it in your phone's browser and use "Add to Home Screen".

Heads-up on security: PINs and admin passwords give convenient, lightweight access control suited to a trusted residents' community — they are not bank-grade encryption. Don't reuse a sensitive personal password here.

Data backup

Download a full backup of everything in this app — flats, owners, PINs, payments, expenses, admin profiles, and settings — as a single CSV file. Keep it somewhere safe; if you ever need to restore, upload it back here.

Restoring a backup replaces all current data in this app with what's in the file — do this only if you're sure.
